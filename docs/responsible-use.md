# Responsible Use

AutoInput is a general-purpose input automation tool intended for legitimate and user-authorized automation.

## Intended uses

AutoInput may be appropriate for:

- Accessibility assistance
- Repetitive productivity tasks
- Local personal workflows
- Software testing
- Demonstrations and controlled automation
- Applications where automation is explicitly permitted

## Prohibited and unsupported uses

AutoInput must not be used for:

- Cheating in games
- Gaining unfair competitive advantages
- Bypassing, weakening, or evading anti-cheat systems
- Violating game, application, website, workplace, or school terms of service
- Automating applications without authorization
- Spam, harassment, botting, credential attacks, scraping where prohibited, or other abusive behavior
- Injecting into protected processes, modifying memory, or defeating application protections

## Games and anti-cheat systems

AutoInput is not an anti-cheat bypass tool. It should not be marketed, documented, or used as a way to avoid detection by games or anti-cheat systems.

Even standard input automation may be prohibited by online, multiplayer, competitive, or anti-cheat-protected games. Users should check the rules of the game or application before using AutoInput.

## Technical stance

AutoInput should only use documented operating-system APIs and user-authorized automation techniques. The project should avoid features whose purpose is to hide automation, evade detection, bypass protections, inject into games, or manipulate protected applications.

## User responsibility

Users are responsible for how they use AutoInput. If a game, application, website, organization, or service does not allow automation, do not use AutoInput with it.
